# 🚀 SummarizeAI - Video & Audio Intelligence Engine

SummarizeAI is a modern AI multimedia summarization, full voice-over speech-to-text transcription, and study notes engine. It is specifically designed for students, content creators, and traders (Forex / Crypto SMC - Smart Money Concepts) to transcribe and summarize long videos (YouTube, lectures, webinars) or audio files into Roman Urdu, Urdu, or English in seconds.

## ✨ Core Features

### 📝 Full Verbatim Transcription
- **Word-by-Word**: Every sentence is transcribed with precise timestamps (e.g., [00:00 - 02:30]).
- **Searchable**: Full transcripts are saved as .txt files for easy searching and copying.

### 🎓 Study Notes & Cheat-sheets
- **High-Yield Notes**: Automatically generates technical trading rules (Order Block, FVG, Liquidity, BOS/CHoCH) and academic summaries.
- **Roman Urdu Intelligence**: Uses natural Pakistani/Hindustani Roman Urdu while keeping technical terms intact.

### 🛠️ Advanced Capabilities
- **Dual View**: Side-by-side comparison of the summary and full transcript.
- **Multi-source Ingestion**: Supports YouTube URLs, MP4/MKV/MP3 uploads, and live microphone recording.
- **Local LLM Powered**: Uses Llama-3 via Ollama for 100% offline, private processing.

## 🚀 How to Use

1. **Source Selection**: Choose your source (YouTube link or local file).
2. **Language Selection**: Select your preferred language (Default: Roman Urdu).
3. **Process**: Click "Summarize & Transcribe".
4. **Review**: View the full transcript and generated study notes.
5. **Save**: Download as .TXT or .MD files.

## 💻 Local Setup Instructions

### Prerequisites
- Python 3.11 / 3.12
- Ollama (with llama3 model pulled: `ollama pull llama3`)
- FFmpeg installed on system

### Installation
```bash
git clone https://github.com/hussainzahidlufi-cmd/summarize-ai.git
cd summarize-ai
pip install -r requirements.txt
```

### Execution
```bash
python ai_studio_optimized.py
```
